Sources: https://www.naturalearthdata.com/about/terms-of-use/ and https://github.com/topojson/world-atlas.
The package license is in WORLD-ATLAS-LICENSE.txt.

Interactive street tiles: © OpenStreetMap contributors, https://www.openstreetmap.org/copyright.
Usage policy: https://operations.osmfoundation.org/policies/tiles/.
Only the displayed map requests tiles directly from the user's browser, with visible attribution,
origin referrer and normal HTTP caching. This code does not proxy or prefetch street tiles.
